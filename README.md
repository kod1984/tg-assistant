# Telegram Keyword Monitor

Асинхронный Telegram-ассистент для отслеживания сообщений в реальном времени
и уведомления по заданным ключевым словам.

## 💡 Use cases

- мониторинг маркетплейсов (Avito, чаты продаж)
- отслеживание вакансий
- поиск редких товаров (например, LEGO, 3D-принтеры)
- фильтрация шума в больших чатах

## 🧠 Как это работает

- Telethon клиент подписывается на новые сообщения
- сообщения фильтруются по ключевым словам
- применяется анти-спам логика (задержки + FloodWait handling)
- отправляется уведомление в target-чат

## 🏗 Архитектура

app/
- client — создание Telegram клиента
- handlers — обработка событий
- filters — логика фильтрации
- sender — безопасная отправка сообщений
- scheduler — контроль активности

## ⚠️ Ограничения

- не обрабатывает медиа
- нет персистентного хранения
- один target-чат

## 🚀 Планы развития

- поддержка нескольких чатов
- хранение истории
- веб-интерфейс
